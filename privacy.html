NODE 7 // SITE INFORMATION

Privacy and Advertising

How local game saves, hosting, advertising technologies, consent choices, and the project’s accountless design work.

Last updated July 2026

Overview

The Last Signal is a browser-based game and informational website. This page explains what the game stores locally, what the site does not currently collect through its own code, and how third-party advertising services may process information on content pages.

Local game saves

The game stores progress in your browser using local storage. This save can include resources, upgrades, unlocked locations, encounter progress, transmissions, settings, elapsed play time, and story state. Local storage remains on the device and browser profile where it was created unless you clear site data.

The Export save feature creates an encoded text representation of the local save and copies it to the clipboard. The site does not automatically upload exported saves. Anyone who receives an exported save string may be able to import and inspect the game state it contains, so treat it as personal game data.

Accounts and analytics

The game does not require an account and does not currently operate its own user database. The site does not currently include a separate first-party analytics service. Hosting providers may process ordinary request information such as IP address, user agent, requested path, and timestamps to deliver and protect the website under their own terms.

Google advertising

Content-oriented pages may load Google AdSense code. Google and its partners may use cookies, local storage, device identifiers, IP addresses, and similar technologies to deliver, limit, personalize, and measure advertising. The exact advertisements shown and the technologies used can depend on region, consent choices, browser settings, and Google’s policies.

The interactive game page at /play.html intentionally does not include Google advertising code. This keeps advertisements away from frequently used gameplay controls and separates the game experience from monetized article content.

Consent and controls

Where required, a consent message may ask visitors to manage advertising choices. Browser privacy controls, cookie settings, content blockers, and Google advertising settings may also affect how ads are delivered. Disabling advertising storage does not disable the game’s separate local save unless all site storage is cleared.

Authorized sellers

The root ads.txt file identifies advertising systems authorized to sell inventory for this publisher. It does not contain visitor information. Its purpose is to help advertisers verify that an advertising request is associated with an authorized seller.

External links

The website links to the project’s GitHub repository. External websites have their own privacy practices, and this policy does not control information processed after you follow an external link.

Changes and questions

This page may be updated when the site adds or removes services. Material changes will be reflected in the text and repository history. Questions and bug reports can be submitted through the public GitHub issue tracker.
